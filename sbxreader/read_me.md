Contains an edited reader.py file for sbxreader that allows it to open scanbox files that don't have a 'knobby' parameter. This needs to be copied directly to your suite2p environment so it can used when registering, aligning, and finding rois in GCaMP data. Typically, this file will be located within your Suite2P installation here, assuming an installation under Anaconda:

C:\Users\user_name\.conda\envs\suite2p\Lib\site-packages\sbxreader
